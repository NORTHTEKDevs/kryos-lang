## Notes

- `fib(35)` — recursive Fibonacci; function-call overhead and branch prediction test.
- `mandelbrot` — 200×200 grid, 1000 max iters; tight floating-point inner loop.
- `nbody` — 5 bodies, 50 000 steps; float arithmetic + indexed array mutation.
- `binary_trees` — pure recursion; depth 18 = 524 288 leaves.
- `fannkuch` — 9!=362 880 permutations with reversal flip counting.
- `matmul` — 256×256 integer matmul; nested-loop indexing throughput test.

Kryos LLVM: `kryos build --release` → clang 19 -O2 backend.
Kryos Cranelift: `kryos build` (fast-compile, unoptimised runtime).
Python >60 means the run exceeded the 60 s timeout.

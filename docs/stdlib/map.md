# std::map

> **Moved:** `Map` is part of `std::collections`.
>
> There is no `std::map` module. The `Map` type -- along with `List`, `Set`, `Stack`, `Queue`, and `Deque` -- is provided by `std::collections`.

```kryos
use std::collections
```

See [std::collections](collections.md) for the full `Map` API, including `Map.new()`, `set`, `get`, `get_or`, `has`, `delete`, `keys`, `values`, `entries`, `merge`, and more.

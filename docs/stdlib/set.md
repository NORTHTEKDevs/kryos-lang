# std::set

> **Moved:** `Set` is part of `std::collections`.
>
> There is no `std::set` module. The `Set` type -- along with `List`, `Map`, `Stack`, `Queue`, and `Deque` -- is provided by `std::collections`.

```kryos
use std::collections
```

See [std::collections](collections.md) for the full `Set` API, including `Set.new()`, `add`, `has`, `delete`, `union`, `intersection`, `difference`, `symmetric_difference`, `is_subset`, `is_superset`, and more.

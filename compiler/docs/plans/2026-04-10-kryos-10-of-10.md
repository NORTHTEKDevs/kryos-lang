## Task 3: Heap-Allocate Trait Object Fat Pointers (Fix Stack Dangling)

**Criticality:** C3 — Stack-allocated fat pointers dangle when dyn Trait values escape scope.

**Files:**
- Modify: `crates/kryos-codegen-cranelift/src/codegen.rs:2658-2692`

**Step 1: Replace `MakeTraitObject` implementation**

Replace the current stack-slot approach (lines 2658-2692) with heap allocation via malloc:

```rust
        RValue::MakeTraitObject { value, concrete_type, trait_name } => {
            let data_val = translate_operand(value, builder, translator, module)?;

            let vtable_key = (concrete_type.clone(), trait_name.clone());
            let method_names = translator.mir_module_trait_methods
                .get(&vtable_key).cloned().unwrap_or_default();

            // Heap-allocate the fat pointer: [data (i64), fn_ptr_0, fn_ptr_1, ...]
            let num_methods = method_names.len().max(1) as u32;
            let alloc_size = (8 + 8 * num_methods) as i64;

            let malloc_ref = ensure_func_ref_with_args(
                "malloc", builder, translator, module, 1,
            )?;
            let size_val = builder.ins().iconst(types::I64, alloc_size);
            let call_inst = builder.ins().call(malloc_ref, &[size_val]);
            let fat_ptr = builder.inst_results(call_inst)[0];

            // Store the data value at offset 0.
            builder.ins().store(MemFlags::new(), data_val, fat_ptr, 0);

            // Store each method function pointer.
            for (i, method_name) in method_names.iter().enumerate() {
                let func_ref = ensure_func_ref_with_args(
                    method_name, builder, translator, module, 1,
                )?;
                let fn_addr = builder.ins().func_addr(types::I64, func_ref);
                builder.ins().store(MemFlags::new(), fn_addr, fat_ptr, 8 + 8 * i as i32);
            }

            Ok(Some(fat_ptr))
        }
```

## Task 4: Recursive Struct Drop — Free Owned Fields Before Freeing Struct

**Criticality:** C4 — Structs with String/Array/Struct fields leak heap memory on Drop.

**Files:**

**Step 1: Replace the Struct drop handler**

Replace the simple `free(val)` call (lines 1425-1431) with recursive field cleanup:

```rust
                        kryos_mir::ir::MirType::Struct(ref struct_name) => {
                            // Free owned fields first, then free the struct itself.
                            if let Some(fields) = translator.struct_defs.get(struct_name) {
                                let (offsets, _) = codegen::compute_struct_layout(fields);
                                for (i, (_, field_ty)) in fields.iter().enumerate() {
                                    match field_ty {
                                        kryos_mir::ir::MirType::Str => {
                                            let field_val = builder.ins().load(
                                                types::I64, MemFlags::new(), val, offsets[i] as i32,
                                            );
                                            let free_ref = ensure_func_ref_with_args(
                                                "kryos_string_free", builder, translator, module, 1,
                                            )?;
                                            builder.ins().call(free_ref, &[field_val]);
                                        }
                                        kryos_mir::ir::MirType::Array(_, _) => {
                                            let field_val = builder.ins().load(
                                                types::I64, MemFlags::new(), val, offsets[i] as i32,
                                            );
                                            let free_ref = ensure_func_ref_with_args(
                                                "kryos_array_free", builder, translator, module, 1,
                                            )?;
                                            builder.ins().call(free_ref, &[field_val]);
                                        }
                                        // Nested structs are pointers too — free recursively
                                        // via the struct's own drop logic. For now, just free
                                        // the nested allocation (shallow).
                                        kryos_mir::ir::MirType::Struct(_) => {
                                            let field_val = builder.ins().load(
                                                types::I64, MemFlags::new(), val, offsets[i] as i32,

                                        }

                                    }
                                }
                            }
                            // Free the struct allocation itself.
```
